*Project Website : [Pyddg](https://www.discretization.de/pyddg/)*

![hippo](https://www.discretization.de/pyddg/doc/v0.4.2/_images/render1.gif)

This is a python library that is used to do projective geometry in Python.

There are two layers to the library, the mathematics and the visualization. The mathematics can transform geometries on different projective subspace. The visualization uses Blender to generate renderings of computations.

I worked mostly on math package of the library. Furthermore I helped create some examples and made renderings for a Projective Geometry book that is aimed to be published soon.
